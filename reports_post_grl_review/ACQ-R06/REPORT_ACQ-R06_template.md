## 2. Challenge clause — wrong or underspecified instructions

1. **The sweep function.** §0 and Part A name `src/discovery/stage_c5_sweep.py:sweep_pair`. The ACQ-R02 chain (`harmonize_new.py`, the development-only block) calls `src/discovery/stage_c2c_recalibrate.sweep(pid, lr_native, thr)` with `pair_dir` redirected to the harmonized directory and the thresholds of `reports/discovery/stage_c2c_calibration.json`; `sweep_pair` reads the June staging HR raster and the raw gridded LR on scratch (purged) with the `stage_c5b_calibration.json` thresholds. The two threshold sets are numerically equal (slope_red −0.97, slope_white −0.8, coh_circular 0.136); the inputs are not. The script calls the chain's function. CONFIRMED by `harmonize_new.py` and the ten rehearsal k values.
2. **Lockbox k.** Part A step 3 says the two lockbox rows "already hold a k". Manifest v2.1 holds NaN for both (`manifest_v2_1.py` filled June k values into development rows only); the June sweep record holds k = 4 for both at the June lr_native (19.7 m, 41.0 m). The script keeps a prior k for `PRIOR_K_PAIRS` (= the lockbox) from the manifest row if present, else from the June record, and records the source; this path was checked on the records (it returns 4 / 4) but could not be rehearsed on data (COULD NOT CHECK on data: no development pair is in `PRIOR_K_PAIRS`, and the modes may differ only in the pair list). HOLD H-3.
3. **The sonar string.** The C2a beam width is `beamwidth_for(<string>)`; the chain's string is the `--sonar` argument that was typed into `sbatch/acq_r02_acquire_list.txt` and recorded in `grid/<cruise>.json`. For a cruise without a grid record the only recorded string is the manifest's `lr_sonar`. The script uses the grid record when it exists, else `lr_sonar`, and records which (`sonar_source`). Strings without a model key fall to the 1.5° default: RR1506 (`"Kongsberg EM (.all) / 20150413"`), both lockbox cruises (`"Kongsberg EM (.all)"`, `"Simrad EM (.all) / 20030729"`), and the confirmatory SUM1004 whose grid record says `None` (its grid was already built at 1.5°). HOLD H-1.
4. **hr_native of June rows.** The chain records `|hr.tif pixel|` (manifest_v2.py: `hr_native_res_m = hr_res_m`); the June rows record the documented AUV native resolution (EW9801 1.982 vs pixel 2.067; NA076 1.0 vs 1.057; RR1506 0.992 vs 1.0). Not a k question, reported for completeness (part of H-1).

### 3.1 Steps and code called
